# How-to

These documents are procedures. Each states what it needs before you start and how to confirm each step.

- [Set up the runners](set-up-runners.md): install the tool, give the horde runner an API key, and set up a local GPU
  environment, reusing an existing worker environment where possible.
- [Render the library](render-library.md): plan and render the library, regenerate one strip, resume an interrupted
  run, and write the derived files, control maps and step-preview strips.
- [Review a batch](review-batch.md): write the contact sheet, pick candidates, answer review questions and write the
  picks back.
- [Run the alchemy campaign](run-alchemy.md): render the alchemy evidence with each of the three backends.
- [Render the tutorial examples](render-tutorial-flows.md): render the worked examples through the horde or locally,
  and the known recipe constraints.
- [Make share cards and the promo gallery](make-promo-material.md): draw cards from the library and make the gallery
  through the live horde.
- [Measure sampler cost](measure-sampler-cost.md): run the per-step sampler cost measurement.
- [Publish the library](publish.md): configure the bucket, check, upload and verify the library and the promo tree.
